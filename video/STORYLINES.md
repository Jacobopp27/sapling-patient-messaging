# Storylines: Sapling patient messaging explainer

The one idea: **the agent answers what the data can answer and hands everything else to staff, safely, because the model only understands and the code decides.**
Viewer: someone who has never seen the project (Jacobo, a reviewer). The film must make sense with the sound off.

Assumptions for all three:
- 60–90 s, 1920×1080, 30 fps.
- On-screen text in Spanish, no voiceover.
- Real screenshots of the running app, not redrawn UI.
- A music bed only if a free catalog track is available; otherwise silent, with one line on how to add one.

## A. Un mensaje, de punta a punta (recommended: one concrete example a stranger can follow)

- **Device and form:** the worked example ("the object is the explanation") as an object-to-object chain.
- **What the viewer sees:** Alex's "yes" leaves the phone and travels through the agent's four stations, each a real part of the code. It lands as a card in the staff console. Then three more messages take the same road and each shows one rule: "Thursday instead" updates the same card, "is it booked yet?" gets "Not yet", and "chest pain" skips the whole machine.
- **First 2 s:** Alex's real phone at Wed 10:00, the clinic's message arriving: "Dr. Lee asked to recheck your blood pressure…"
- **Beats:** clinic message → "yes" → the 4 stations (emergency guard, interpreter, handler + tools, reply guard) → card lands in the staff queue → "Thursday instead": same card, count stays 1 → "is it booked yet?": "Not yet" → chest pain: red bypass, exact text → server off and on: the list survives → one line: "El modelo entiende. El código decide."
- **Look:** the app's own world. Thread beige #efeae2, Sapling green #1f5c43, bubble green #d9fdd3, system UI sans. The machine is drawn as one pipe that grows a station per beat.
- **Sound:** calm, light pulse around 100 bpm. Soft pop when a card lands, one whoosh on the emergency bypass, the music drops to near silence for the emergency and comes back for the end line.

## B. Dos pantallas

- **Device and form:** life on both sides of the thread, as a split screen that opens into one.
- **What the viewer sees:** Alex's phone on the left and the clinic console on the right, each showing only what that person sees. Then the seam between them opens to reveal the machine in the middle: product first, technique second.
- **First 2 s:** the two screens side by side; Alex types "yes" on the left and nothing happens yet on the right.
- **Beats:** both sides idle → Alex asks things, the console fills with answered vs filed → the seam opens: the pipeline between the two screens → safety rules shown as what the middle refuses to do → both screens again, now understood → end line.
- **Look:** the same app palette, a darker green seam (#173f2f) for the machine.
- **Sound:** a two-note motif, one per side, joined when the seam opens.

## C. Las reglas que no se rompen (bold)

- **Device and form:** type carries the argument; one frame that rebuilds.
- **What the viewer sees:** giant Spanish lines state each rule ("nunca agenda", "nunca da consejo médico", "el texto de emergencia, exacto"). A real message then tries to break each rule, and the frame shows the code that stops it: the reply guard stamping BLOCKED, the emergency text appearing letter for letter.
- **First 2 s:** "should I take two pills?" typed huge, and the word "two" gets struck through.
- **Beats:** attack 1 (dosing) → "Nunca da consejo" → attack 2 ("is it booked?") → "Nunca dice booked" → attack 3 (chest pain) → "Texto exacto" → attack 4 (restart) → "No olvida nada" → end line.
- **Look:** Sapling green full-bleed planes, cream type, red only for BLOCKED.
- **Sound:** a drum hit per rule, silence before the emergency text.
